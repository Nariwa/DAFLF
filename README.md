## Публикация на GitHub Pages
1. Распакуйте ZIP.
2. Загрузите ВСЕ файлы и папку assets в корень репозитория. index.html должен находиться в корне, а не внутри дополнительной папки. Сам ZIP загружать не нужно.
3. В репозитории откройте Settings → Pages.
4. Выберите Deploy from a branch, ветку main и папку /(root), затем Save.
5. Дождитесь публикации и откройте адрес, который покажет GitHub.

Сборка, npm, сервер и API-ключи не нужны. Все пути к ресурсам относительные, поэтому сайт работает и по адресу репозитория /repository-name/.

## Редактирование
index.html — весь текст и обе векторные композиции, компьютерная и мобильная.
style.css — шрифт и переключение макетов.
app.js — кнопки, источники, скачивание пожеланий, точки и сканер.
details.js — пунктир, зачёркивание и группы сообщений.
reveal.js — появление текста и сообщений.
assets — локальный шрифт, его лицензия и векторные файлы.

Геометрия авторских SVG сохранена. Макеты пропорционально масштабируются, переключение на мобильный — при ширине 700 px. Текст в SVG остаётся текстом. При редактировании длинных фраз проверяйте переносы.

Это версия после удаления линий между экранами одного цвета и объединения фразы «Но страница может быть нужна тому, кто остался». Анимации сохранены из выбранной автором версии до последних экспериментов с мобильным появлением.

Ответы формы обрабатываются в браузере. Страница не отправляет их на сервер. Источники открываются на внешних сайтах. Автоматическое уменьшение движения учитывает системные настройки.
